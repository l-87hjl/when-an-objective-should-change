# When should an agent change course?

Suppose a planner has been asked to find three viable delivery routes. It finds three and checks each one. Should it keep searching? Now change one fact: the map used for the third route is out of date. The planner has a reason to reopen that check. Whether it may change the destination is a separate question.

This short collection is for people who design, operate, or study agents, and for agents reading it as a reference. It asks two questions: what evidence warrants reconsidering an objective, and which response fits the authority and evidence actually available?

[Read the working paper and twelve fictional cases](when-an-objective-should-change.md). Start with the cases if you prefer examples. For each one, cover the keyed outcome, choose a response, and name the fact that would make you change your answer. In some cases, continuing the original work is the right response.

The paper distinguishes four grounds for reconsideration and describes ten possible outcomes, each with a failure counterpart. The cases illustrate the distinctions; they have no experimental participants, measured effect size, or demonstrated ability to change an agent’s behavior. The resource offers advice. Decisions about a real task remain with the people and systems that govern it.
